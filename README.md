# Multi-Target Radar Tracking Simulator

A from-scratch implementation of a radar tracking pipeline: simulating maneuvering
targets, noisy sensor measurements, and (in progress) an Unscented Kalman Filter
with multi-target data association.

## Status: In Progress
- [x] Ground truth trajectory simulation (constant turn-rate model)
- [x] Noisy radar sensor simulation (range/bearing measurements)
- [ ] Unscented Kalman Filter
- [ ] Multi-target data association
- [ ] Track management
- [ ] Validation (RMSE, NEES)
